# TextSplitterLangchain

A repository dedicated to exploring, implementing, and experimenting with various Text Splitters and Chunking strategies in LangChain for RAG (Retrieval-Augmented Generation) pipelines.

## Overview

Text splitting is a critical preprocessing step in RAG systems to break large documents into manageable chunks while preserving semantic context.

Topics covered:
- Character Text Splitters
- Recursive Character Text Splitters
- Token-based Splitters (tiktoken, etc.)
- Markdown / Code Text Splitters
- Semantic Chunking & Advanced Splitters
